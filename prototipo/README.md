# Prototipo Streamlit (solo referencia)

Versión anterior de StatLab ML en Streamlit. **No forma parte de la aplicación**:
se conserva como referencia del flujo, los textos y las decisiones de cada gráfico
(`statlab_ml/plots.py`: paleta, símbolos, ejes) mientras se construye la versión de
escritorio. El motor (`kmeans_core.py`) ya vive en `src/statlab/core/kmeans.py`, y
este código no se ejecuta ni se testea. Se puede borrar cuando la versión de
escritorio cubra todo lo que hacía.
